'https://editor.plantuml.com/
'Activity Diagram 3: Different usage modes of Testimize

@startuml
skinparam shadowing false
skinparam roundcorner 0
skinparam linetype ortho
skinparam nodesep 80
skinparam ranksep 50

start

:User selects operation mode;

if (Precise mode selected?) then (yes)
  :Create configuration with explicit parameters;
  :Define validation rules and test values;
else (no)
  :Auto-discover input parameters;
  :Generate values using built-in strategies;
endif

:Initialize TestimizeEngine;
:Apply parameters and settings;

:Select test generation strategy;

if (Use Pairwise generation?) then (yes)
  :Generate test cases using Pairwise algorithm;
else (no)
  :Generate test cases using Hybrid ABC algorithm;
endif

:Output results through selected OutputGenerator;

:Review results and perform analysis;

if (Errors detected in test suite?) then (yes)
  :Reconfigure parameters or fix issues;
  -> Initialize TestimizeEngine;
else (no)
  :Test suite generation complete;
endif

stop
@enduml
